# Week 2 – Data analyseren en visualiseren

**Startdatum:** 01-11-2026  
**Einddatum:** 16-11-2026


## Doel van deze week

Deze week wil ik de opgehaalde koersgegevens met Python analyseren en de resultaten met JavaScript dynamisch weergeven.

## Taken deze week

- Verschillende berekeningen uitvoeren met Python op basis van de beschikbare koersgegevens.
- De berekende resultaten vanuit Django doorsturen naar JavaScript.
- Verschillende containers maken om statistieken en resultaten weer te geven.
- Een chart implementeren om koersgegevens visueel te presenteren.
- De resultaten testen met één aandeel.

## Leerdoelen

- Leren hoe ik koersgegevens met Python analyseer.
- Leren hoe ik berekende gegevens vanuit Django naar JavaScript stuur.
- Leren hoe ik resultaten dynamisch weergeef met JavaScript.
- Leren hoe ik financiële gegevens visualiseer in een chart.

## Verwacht resultaat

De gebruiker kan één aandeel opzoeken en de beschikbare koersgegevens analyseren.
