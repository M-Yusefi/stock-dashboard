# Week 1 – Django-project opzetten en API-integratie

**Startdatum:** 02-11-2026  
**Einddatum:** 09-11-2026

## Taken deze week

- Een nieuw Django-project opzetten en de basisconfiguratie instellen.
- De projectstructuur bedenken en de benodigde mappen en bestanden aanmaken.
- Bootstrap integreren om de vormgeving van de webapplicatie op te bouwen.
- Een verbinding maken met een extern API-endpoint om koersgegevens van aandelen op te halen.
- Een JavaScript-zoekfunctie ontwikkelen waarmee gebruikers aandelen kunnen zoeken.
- De communicatie tussen JavaScript en Django voorbereiden voor het verwerken van zoekopdrachten.

## Leerdoelen

- Leren hoe ik een Django-project opzet en configureer.
- Leren hoe ik een logische projectstructuur opbouw binnen Django.
- Leren hoe ik Bootstrap integreer in een Django-project.
- Leren hoe ik vanuit Python verbinding maak met een extern API-endpoint.
- Leren hoe JavaScript en Django met elkaar communiceren.

## Verwacht resultaat

Aan het einde van deze week staat de basis van de Django-webapplicatie. Bootstrap is geïntegreerd, de projectstructuur is opgezet en er is een verbinding met een extern API-endpoint. Daarnaast is een JavaScript-zoekfunctie ontwikkeld waarmee gebruikers aandelen kunnen zoeken.
